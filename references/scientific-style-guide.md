# scientific-style-guide.md — 科研图视觉规范

模型设计 spec 时遵循本规范，让输出接近期刊可用的科研图质量。规则按重要性排列，无法同时满足时优先靠前的。

## 1. 布局

- 信号/机制图默认**自上而下**传导（输入/配体在上，下游/靶基因在下），边尽量笔直，少交叉。
- 流程图默认自上而下；分支收敛处用菱形判断节点。
- 同一层（rank）内的节点尽量等高；并列关系放同一行。
- 容器（细胞膜、细胞核、Phase 1/2/3）用于表达空间或阶段分组，不要滥用。
- 交叉不可避免时，把被交叉的边设为 `dashed` 或 `curved` 降低视觉冲突。

## 2. 颜色（默认主题 nature，类 Cell 风格）

| 用途 | tone | 色 |
|---|---|---|
| 主要通路核心节点 | `default` | 蓝 #4C72B0 |
| 分支/替代通路 | `alt` | 橙 #DD8452 |
| 下游效应/产物 | `alt2` | 绿 #55A868 |
| 抑制/负调控节点 | `alt3` | 红 #C44E52 |
| 修饰/复合物 | `alt4` | 紫 #8172B3 |
| 结构/非活性 | `muted` | 浅灰蓝 #EAF0F6 |

- 颜色承担语义，不承担装饰：同一语义全图一致（如"抑制节点一律 alt3 红"）。
- 白字放深色填充、深字放浅色填充（脚本自动处理 fontColor，无需手写）。
- 投稿线图（黑白打印）用 `minimal` 主题；PPT/组会汇报用 `nature`；彩色投稿且需色盲安全时用 `colorblind`（Okabe-Ito 配色，红绿/蓝紫均可区分，满足期刊色盲安全要求）。

## 3. 线宽与箭头

- 默认边线宽 2，重点通路可 2.5–3，背景/间接关系 1.5 或虚线。
- 箭头语义固定五类，全图统一（见 schema 箭头表）：
  - 激活 → 实心三角；抑制 → **⊥ T 形条**；转位 → 空心 V；结合 → 圆点；生成 → 实心三角。
- 抑制关系的 T 形条是科研图关键约定，务必用 `inhibition` 而非实心箭头。
- 标签放边上，字号 ≤ 节点字号；短词优先（"激活"而非"促进激活过程"）。

## 4. 字体与文本

- 节点标签默认 12px；标题 16px 加粗；注释/图例 11px。
- 蛋白/基因名用标准写法：基因斜体（`<i>EGFR</i>`）、蛋白正体；亚基用 `<sub>`。
- 标签要短（≤ 12 字），细节放 `notes`。
- 复合标签用 HTML：`<b>GRB2</b>/<sub>adaptor</sub>`。

## 5. 常见图类型画法

- **信号通路图**：配体/受体在顶层，激酶级联逐层向下，转录因子→靶基因收尾；磷酸化用 activation 箭头+标签"磷酸化"；负反馈环回到上游节点（可画成 curved 虚线）。
- **实验流程图**：每个步骤一个 `process`/`rect`，条件用 `rhombus`，样本分组用容器（如"处理组/对照组"）；时间顺序自上而下。
- **研究框架图**：3–4 个横向区块（背景→问题→方法→结论），区块用容器，内部条目用圆角矩形，区块间用粗线连接。
- **知识图谱/概念图**：概念用 `ellipse`，关系标签写在边上，用 `association` 箭头。
- **生信流程**：数据→质控（rhombus 判断）→比对→定量→统计，数据库用 `cylinder`。

## 6. 自解释原则

- ≥3 种箭头语义必须配 `legend`。
- 任何"间接/推测/待验证"关系用 `dashed` 并在 `notes` 说明。
- 图必须能脱离正文看懂：标题、图例、必要注释齐备。

## 7. 期刊导出参数（投稿用）

导出命令：`python scripts/sci_drawio.py export out.drawio -f png/svg/pdf -o out --border 16 --scale N`。

| 期刊/场合 | 目标宽度 | 建议导出 |
|---|---|---|
| Nature/Science 单栏 | 89 mm（≈3.5 in） | 以最终尺寸导出，PNG ≥300 DPI 或直接 SVG/PDF 矢量 |
| Nature/Science 双栏 | 183 mm（≈7.2 in） | 同上 |
| IEEE / Elsevier 单栏 | 3.5 in | SVG/PDF 优先 |
| 中文期刊单栏 | 8–9 cm | PNG ≥300 DPI 或矢量 |
| PPT/组会汇报 | 不限 | PNG 即可（`--scale 1.5` 放大更清晰） |

要点：

- **矢量优先**：示意图投稿用 SVG/PDF（draw.io 导出无损）；位图才用 PNG，**不低于 300 DPI**（对应 `--scale` 调高 + 大 `--border`）。
- **字号在最终尺寸下可读**：导出后按最终尺寸目测，节点文字 ≥6 pt 等效；过小则加大节点或缩小图整体后重导。
- **按最终尺寸出图，不二次缩放**：导出时直接设好 `--scale`/`--border`，避免投稿前放大导致发虚。
- **灰度检查**：`minimal` 主题天然适合黑白打印；彩色图投稿前把 PNG 转灰度确认色块/箭头可区分（色盲友好，见 viz-pitfalls.md P8）。
